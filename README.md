🔍 Program Description
This C program is a console-based Sudoku game that allows users to play Sudoku with customizable board sizes (4x4, 9x9, 16x16) and difficulty levels (Easy, Medium, Hard). It features a simple menu system with options to start a new game, load a saved game, view instructions, or exit. The game uses dynamic memory allocation for the board and provides file I/O functionality to save and load the game state.

Key components include:

Board generation: Randomly creates a complete and valid Sudoku board.

Difficulty setting: Removes a percentage of numbers based on the chosen difficulty.

User input system: Accepts player moves and validates them against Sudoku rules.

Game state saving/loading: Allows players to save the game (-1 -2 -3) or quit (0 0 0).
